# 勉強タイマー ご褒美の試作

勉強の時間をタイマーで測り、終わった後に「昨日・先週・先月の自分を超えたか」を結果発表で見せ、宝箱を指で叩いて割る流れを試すための試作ページです。

- 記録は端末の中（localStorage）だけに残り、どこにも送りません。
- 音はブラウザの中で合成しています（消音スイッチの時は鳴りません）。
- `?mute=1` で音を全部止めます。
- 数字の字（Barlow Condensed）と、iPhone 以外で使う日本語の字（Noto Sans JP）は Google Fonts から読み込みます。
